# PasteNest 隐私政策

生效日期：2026-09-16

PasteNest（「本应用」）是一款 macOS 菜单栏剪贴板历史工具。我们重视你的隐私：默认情况下，数据只留在你的 Mac 上。

## 我们收集哪些数据

**我们不收集、不上传、不出售你的个人数据。**

本应用：

- 没有开发者运营的账号体系
- 没有分析 SDK、广告 SDK、崩溃上报第三方
- 不做跨 App 追踪（`NSPrivacyTracking` 为 false）

剪贴板历史（文本、链接、图片、文件引用、截图、识别出的文字等）只保存在你这台 Mac 的本地数据库中。

## iCloud 同步（可选）

若你在系统设置中登录了 iCloud，并在 PasteNest 里开启同步：

- 数据通过 **你自己的 iCloud 账号** 在你的多台 Mac 之间同步
- 传输由 Apple 的 CloudKit 处理
- **开发者无法访问、查看或下载这些内容**

不开启同步时，全部功能仍可在本地使用。

## 系统权限

本应用可能请求下列 macOS 权限。你可以拒绝；拒绝后对应能力不可用，其余功能仍可使用。

| 权限 | 用途 |
|------|------|
| 辅助功能 | 把选中的历史记录粘贴到当前应用 |
| 屏幕录制 | 截取屏幕、标注后存入剪贴板历史 |
| 用户选定的文件 | 导出历史 JSON 等你主动触发的文件操作 |

本应用会读取系统剪贴板，以便保存你复制的内容。请避免在不信任的场景下复制密码、验证码等敏感信息；你可随时在应用内删除条目。

## 本地技术存储

本应用使用 UserDefaults 保存界面偏好（快捷键、主题、保留天数等），这些数据留在本机，不会发往开发者服务器。

## 儿童

本应用分级 4+，不面向儿童收集数据。

## 第三方

除可选的 Apple iCloud / CloudKit 外，本应用不向第三方分享数据。App Store 的购买与付款由 Apple 处理，适用 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 政策更新

若实践发生变化，我们会更新本页并调整「生效日期」。继续使用即表示你了解更新后的政策。

## 联系我们

有隐私相关问题，请通过应用在 App Store 上的技术支持链接（GitHub Issues 或你提供的邮箱）联系开发者。
