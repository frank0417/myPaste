# 好记英语 · App Store 上架素材

基于 8 张 app 功能截图整理制作的 App Store 上架截图与营销素材。
所有成品均为高清 PNG（RGB，无透明通道），可直接上传 App Store Connect。

## 目录结构

```
appstore-assets/
├── appstore/
│   ├── 6.9-inch_1320x2868/   # 6.9 英寸（iPhone 16 Pro Max）— App Store 必传
│   └── 6.5-inch_1242x2688/   # 6.5 英寸（iPhone 11 Pro Max / XS Max）
├── marketing/
│   ├── banner-1920x1080.png  # 营销横幅（官网 / 社交媒体 / 广告投放）
│   └── square-1080x1080.png  # 方形营销图（朋友圈 / 微博 / 小红书等）
├── source/                   # 原始截图（按功能重命名）
│   └── corrected/            # 方向已扶正的原始截图（部分源图为逆时针存储）
└── tools/
    └── generate_screenshots.py   # 素材生成脚本，可修改文案后重新生成
```

## 上传说明

1. App Store Connect → 我的 App → 选择版本 → 「App 预览和截屏」。
2. **6.9 英寸**为必填尺寸：上传 `appstore/6.9-inch_1320x2868/` 中的 8 张，
   按文件名 01→08 顺序拖入。
3. **6.5 英寸**可选：上传 `appstore/6.5-inch_1242x2688/`；不上传则自动复用 6.9 英寸版本。
4. 若 app 支持 iPad，还需单独准备 iPad 截图（12.9 英寸 2048×2732），
   本套素材不包含 iPad 尺寸。
5. 截图语言为简体中文，适用于「简体中文」本地化；如需其他语言地区上架，
   请在对应语言下单独上传或设置为默认语言素材。

## 重新生成

```bash
pip install pillow
python3 tools/generate_screenshots.py
```

修改 `tools/generate_screenshots.py` 中的 `SCREENS` 配置即可调整文案、
截图顺序与特性胶囊；品牌渐变色在 `BRAND_TOP` / `BRAND_BOTTOM` 中调整。

## 设计说明

- 深色高级质感风格（参照营销样图）：炭灰渐变背景 + 柔光，白色主标题 +
  品牌绿副标题，界面截图以圆角卡片 + 柔和投影悬浮呈现，底部两个卖点
  （绿色图标字 + 白色标题 + 灰色描述）。
- 源图分辨率有限的部分（约 570–620px 宽）已限制放大倍数 ≤1.5x 并做锐化，
  保证成品清晰度；后续若能提供真机全分辨率截图（1242×2688 或 1320×2868），
  替换 `source/` 中对应文件并重新运行脚本即可获得更锐利的效果。
