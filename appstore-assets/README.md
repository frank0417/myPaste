# 背单词 App · Mac App Store 上架素材

基于您提供的 8 张 app 原始截图制作。**页面内容 100% 保留原样**, 仅做:
方向修正 → 2x 高清放大 → 锐化增强 → 套 Mac App Store 营销版式。
所有成品均为高清 PNG（RGB），可直接上传 App Store Connect。


## 上传说明（Mac App Store）

1. App Store Connect → 我的 App → 选择版本 → 「App 预览和截屏」→ 选择 **Mac**。
2. 上传 `appstore/mac_2560x1600/` 中的 8 张，按文件名 01→08 顺序拖入。
3. Mac 截屏接受 1280×800 / 1440×900 / 2560×1600 / 2880×1800，本套采用
   2560×1600（视网膜高清），无需其他尺寸。
4. 截图语言为简体中文；如需多语言地区上架，请在对应语言下单独上传。

## 图片处理说明

- **内容零改动**：页面 UI、文字、布局完全保留原图，未简化、未替换。
- **方向修正**：02（单词卡片）、04（词汇量测试）两张源图为逆时针旋转 90°
  存储，已顺时针扶正。
- **清晰度增强**：所有源图经 2 倍高质量放大（Lanczos）+ 双次锐化，
  增强版保存在 `source/enhanced/`；营销图中的界面均为增强版合成，
  文字边缘明显更锐利。
- **营销版式**：深色炭灰渐变背景（参照营销样图）+ 白色主标题 + 亮绿副标题
  （绿色取自 app 主色）+ macOS 窗口栏（红黄绿按钮，不含品牌名）+
  底部双卖点。

## 重新生成

```bash
pip install pillow
python3 tools/generate_screenshots.py
```

修改 `tools/generate_screenshots.py` 中的 `SCREENS` 配置即可调整文案与卖点。
若后续有更高分辨率的原始截图，替换 `source/` 中对应文件（注意保持
文件名一致，旋转方向在 `rotate` 字段配置）后重跑脚本即可。
