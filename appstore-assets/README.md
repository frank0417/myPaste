# 好记英语 · App Store 上架素材

基于 8 张 app 功能截图整理制作的 **Mac App Store** 上架截图与营销素材。
所有成品均为高清 PNG（RGB，无透明通道），可直接上传 App Store Connect。

## 目录结构

```
appstore-assets/
├── appstore/
│   ├── mac_2560x1600/        # Mac App Store 上架截图（主交付，2560×1600 视网膜高清）
│   ├── 6.9-inch_1320x2868/   # iPhone 尺寸（备用，仅当后续上架 iOS 版时需要）
│   └── 6.5-inch_1242x2688/   # iPhone 尺寸（备用）
├── marketing/
│   ├── banner-1920x1080.png  # 营销横幅（官网 / 社交媒体 / 广告投放）
│   └── square-1080x1080.png  # 方形营销图（朋友圈 / 微博 / 小红书等）
├── source/                   # 原始截图（按功能重命名）
│   └── corrected/            # 方向已扶正的原始截图（部分源图为逆时针存储）
└── tools/
    └── generate_screenshots.py   # 素材生成脚本，可修改文案后重新生成
```

## 上传说明（Mac App Store）

1. App Store Connect → 我的 App → 选择版本 → 「App 预览和截屏」→ 选择 **Mac**。
2. 上传 `appstore/mac_2560x1600/` 中的 8 张，按文件名 01→08 顺序拖入。
3. Mac 截屏接受 1280×800 / 1440×900 / 2560×1600 / 2880×1800，本套采用
   2560×1600（视网膜高清），无需其他尺寸。
4. 截图语言为简体中文；如需多语言地区上架，请在对应语言下单独上传。
5. `6.5-inch` / `6.9-inch` 目录为 iPhone 尺寸备用素材，仅 Mac 上架可忽略；
   若 app 后续开放 iOS 版可直接使用。

## 重新生成

```bash
pip install pillow
python3 tools/generate_screenshots.py
```

修改 `tools/generate_screenshots.py` 中的 `SCREENS` 配置即可调整文案、
截图顺序与底部卖点；主题色值在文件顶部常量区调整。

## 设计说明

- 深色高级质感风格（参照营销样图）：炭灰渐变背景 + 柔光，白色主标题 +
  品牌绿副标题，底部两个卖点（绿色图标字 + 白色标题 + 灰色描述）。
- Mac 版截图带原生 macOS 窗口栏（红黄绿按钮 + 居中「好记英语」标题），
  呈现真实 Mac 窗口效果。
- 源图分辨率有限的部分（约 570–620px 宽）已限制放大倍数 ≤1.5x 并做锐化，
  保证成品清晰度；后续若能提供更高分辨率的窗口截图（建议窗口宽度
  ≥1700px），替换 `source/` 中对应文件并重新运行脚本即可获得更锐利的效果。
